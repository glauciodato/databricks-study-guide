Aula - Ingestão de Dados Semiestruturados: JSON

Visão Geral

Nesta aula, você aprenderá como a ingestão de dados semiestruturados, como JSON, permite a análise e transformação eficiente de entradas complexas e aninhadas em tabelas UC estruturadas para analítica avançada no Lakehouse.

Objetivos de Aprendizagem

Ao final desta aula, você será capaz de:

  1. Descrever a estrutura dos dados JSON incluindo objetos, chaves, valores, objetos aninhados e arrays
  2. Explicar três abordagens para trabalhar com colunas JSON: tipos de dados STRING, STRUCT e VARIANT
  3. Mapear tipos JSON para tipos de dados do Databricks SQL e definir esquemas STRUCT para JSON aninhado
  4. Usar schema_of_json e from_json para derivar e aplicar esquemas ao converter strings JSON em colunas STRUCT
  5. Descrever o tipo de dado VARIANT e seus benefícios para dados semiestruturados

A ingestão de dados semiestruturados como JSON permite a análise e transformação eficientes de entradas complexas e aninhadas em tabelas UC estruturadas para analítica avançada no Lakehouse.

Entender o formato do JSON é importante porque ele afeta a forma como analisamos e transformamos os dados durante a ingestão.

B. Trabalhando com Colunas Formatadas em JSON

Ao trabalhar com dados JSON, é comum que após a ingestão uma ou mais colunas da sua tabela contenham strings formatadas em JSON como valores.

B1. Coluna STRING Formatada como JSON

A questão aqui é: como trabalhar com colunas que armazenam strings formatadas como JSON?

Este é um cenário comum quando o JSON não é totalmente analisado durante a ingestão, ou quando dados JSON estão incorporados em outro campo, como uma mensagem de log ou uma estrutura aninhada.

json_column
'{"name": "John Doe", "age": 35, "address": {"city": "Anytown", "state": "CA"}, "children": [{"name": "Owen", "age": 10}, {"name": "Eva", "age": 8}]}'
'{"name": "Kristi Doe", "age": 40, "address": {"city": "Anytown", "state": "CA"}, "children": [{"name": "Steve", "age": 10}]}'
...

Colunas em tabelas podem conter strings formatadas em JSON como valores

B2. Métodos de Coluna com Strings Formatadas em JSON

Vamos explorar técnicas para analisar, extrair e manipular essas strings JSON usando SQL ou operações com DataFrame, para que você possa nivelar e/ou acessar os campos aninhados como colunas comuns.

Uma técnica para trabalhar com uma coluna de string formatada em JSON é acessar os valores diretamente da coluna do tipo de dado STRING.

  • JSON pode ser armazenado como uma STRING simples
  • Pode conter qualquer conteúdo JSON sem restrições — é apenas texto bruto
  • Menos eficiente em comparação com abordagens tipadas

Outro método para trabalhar com uma coluna de string formatada em JSON é converter a coluna para o tipo de dado STRUCT.

  • Você pode analisar dados JSON em um tipo STRUCT com um esquema definido
  • STRUCT impõe o esquema JSON, garantindo que os tipos de dados e a estrutura sejam consistentes
  • É mais eficiente para consultas do que uma STRING formatada em JSON

EXPANDIR PARA NOTAS ADICIONAIS
  1. Tipo de Dado STRING
    Uma técnica para trabalhar com uma coluna de string formatada em JSON é acessar os valores diretamente a partir da coluna do tipo de dado STRING. - Uma coluna pode simplesmente armazenar dados JSON como uma STRING simples - Por ser armazenada como string, a coluna pode conter qualquer string JSON sem restrições - No entanto, essa abordagem tem desempenho inferior em comparação com abordagens tipadas como STRUCT Para acessar subcampos em colunas de string formatadas em JSON, você pode usar a sintaxe de dois-pontos (:). Por exemplo, se sua coluna se chama json_column e você deseja acessar o subcampo "name", você o especificaria como: json_column:name Essa sintaxe permite extrair campos específicos diretamente da string JSON armazenada na coluna.
  2. Tipo de Dado STRUCT
    Outro método para trabalhar com uma coluna de string formatada em JSON é converter a coluna para o tipo de dado STRUCT. - Você pode analisar dados JSON em um tipo STRUCT definindo um esquema - O STRUCT impõe o esquema JSON, garantindo que os tipos de dados e a estrutura sejam consistentes - Consultar um STRUCT é mais eficiente do que trabalhar com uma STRING formatada em JSON bruta.

  3. Tipo de Dado VARIANT
    O tipo de dado VARIANT é a abordagem mais recente para trabalhar com dados JSON no Databricks. A partir do segundo trimestre de 2025, o VARIANT está em pré-visualização pública. Os principais benefícios incluem: - Pode armazenar qualquer tipo de dado, incluindo JSON, tornando-o ideal para dados semiestruturados - Altamente flexível, adaptando-se a diferentes formatos de dados sem esquemas rígidos - Oferece desempenho aprimorado em relação aos métodos existentes (STRING e STRUCT) Fique atento ao lançamento de sua Disponibilidade Geral (GA).

EXPANDIR PARA NOTAS ADICIONAIS
Agora, vamos percorrer o processo de mapeamento de uma STRING formatada em JSON para uma coluna STRUCT. - O primeiro passo é definir o esquema, ou estrutura, da string formatada em JSON. Definir o esquema informa ao Databricks como interpretar cada parte da string JSON e convertê-la nos tipos de dados apropriados dentro de um STRUCT. - Primeiro, o tipo de dado `STRUCT<>` é usado para armazenar toda a estrutura da string formatada em JSON. Ele atua como um contêiner para todos os campos definidos no JSON, preservando seus tipos de dados e hierarquia dentro de uma única coluna. - Em seguida, percorra os pares key-value do JSON um a um e defina a estrutura para cada campo. - A key `name` contém um valor do tipo string, enquanto a key `age` contém um valor do tipo inteiro. - A key `address` contém outro objeto, que é representado como um `STRUCT` aninhado. Esse `STRUCT` aninhado inclui duas keys: `city` e `state`. Tanto `city` quanto `state` utilizam o tipo de dado string. - A key `children` contém um `ARRAY` de `STRUCTS`. Cada `STRUCT` dentro do array inclui duas keys: `name` e `age`. A key `name` contém um valor do tipo string, e a key `age` contém um valor do tipo inteiro.

D. Estrutura da String JSON

Após revisar como mapear uma STRING formatada em JSON para uma coluna STRUCT, vamos aprender como determinar facilmente a estrutura da string JSON.

Isso pode ser feito em dois passos:

  1. Obter o schema da string formatada em JSON usando schema_of_json
  2. Usar a função from_json para aplicar o schema e analisar a coluna

D1. Passo 1: Derivando o Schema com schema_of_json

Em vez de definir o schema manualmente, você pode usar a função integrada schema_of_json para derivar automaticamente o schema a partir de uma string JSON de exemplo.

Basta passar uma string no formato JSON como argumento para essa função, e ela retornará o schema (estrutura) inferido.

{
  "name": "John Doe",
  "age": 35,
  "address": {
    "city": "Anytown",
    "state": "CA"
  },
  "children": [
    { "name": "Owen", "age": 10 },
    { "name": "Eva", "age": 8 }
  ]
}

D2. Passo 2: Analisando JSON com from_json

Depois de ter a estrutura da string formatada em JSON, você pode usar a função from_json do Spark. Essa função recebe a string JSON e o esquema especificado obtido no passo anterior, e retorna uma coluna do tipo STRUCT.

Usar from_json criará uma nova coluna com o tipo de dado STRUCT, contendo os dados JSON analisados de acordo com o esquema definido.

STRUCT<
  name: STRING,
  age: INT,
  address: STRUCT<
    city: STRING,
    state: STRING
  >,
  children: ARRAY<
    STRUCT<name: STRING, age: INT>
  >
>
2
Aplicar o esquema com from_json
SELECT from_json(json_col, 'json-struct-schema') AS struct_column FROM table

A função from_json retorna uma coluna struct usando a string JSON e o esquema especificado

E. Conclusão

Nesta aula, você aprendeu a trabalhar com dados JSON semiestruturados no Databricks:

  • Estrutura JSON: Objetos delimitados por chaves contêm pares Key-value. Os valores podem ser strings, números, booleanos, arrays ou objetos aninhados.
  • Três abordagens para trabalhar com colunas no formato JSON:
  • STRING: Simples, porém com menor desempenho. O JSON é armazenado como texto bruto.
  • STRUCT: Faz o parse do JSON com um esquema definido. Impõe estrutura e é mais eficiente para consultas.
  • VARIANT: A abordagem mais recente (prévia pública). Altamente flexível e com desempenho aprimorado.
  • Conversão de JSON para STRUCT requer o mapeamento dos tipos JSON para os tipos do Databricks SQL (STRING, INT, BOOLEAN, STRUCT<>, ARRAY<>).
  • Use schema_of_json para derivar automaticamente o esquema a partir de uma string JSON de exemplo.
  • Use from_json para fazer o parse de uma coluna de string JSON em uma coluna STRUCT utilizando o esquema derivado.
