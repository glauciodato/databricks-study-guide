EXPANDA PARA NOTAS ADICIONAIS
#### O Kit Completo do LakeFlow Connect Este visual apresenta os três pilares de ingestão de dados que você explorou em todas as aulas, demonstrações e laboratórios. Cada um complementa os demais para entregar tabelas Bronze governadas e prontas para análise no Lakehouse. #### Conectores do LakeFlow Connect O LakeFlow Connect é a camada de ingestão de dados da Databricks Data Intelligence Platform — ele substitui o conjunto fragmentado tradicional de ferramentas de ingestão por uma única superfície gerenciada: - **Upload Files** — cargas ad-hoc de arquivos locais em volumes ou tabelas do Unity Catalog - **Conectores Padrão** — armazenamento de objetos cloud, Kafka e outras fontes, com suporte a ingestão em lotes, lotes incrementais e transmissão - **Conectores Gerenciados** — ingestão totalmente gerenciada e orientada por interface a partir de bancos de dados corporativos e aplicações SaaS (Salesforce, Workday, SQL Server e outros) - **Partner Connect** — soluções de parceiros validadas quando um conector gerenciado nativo não está disponível #### Métodos de Ingestão O método adequado depende do volume de dados, da atualidade e do padrão operacional: - **CREATE TABLE AS (CTAS)** com `read_files()` — ingestão em lotes simples que cria tabelas UC a partir de arquivos brutos. Ideal para cargas ad-hoc únicas ou de menor escala. - **COPY INTO** — ingestão incremental em lotes idempotente e repetível. Ignora arquivos já carregados; ideal para pipelines agendados que processam milhares de arquivos. - **Auto Loader** (Python `cloudFiles` ou tabelas de transmissão SQL em Declarative Pipelines) — a opção mais escalável. Suporta evolução automática do esquema e processa bilhões de arquivos para cargas de trabalho incrementais ou de transmissão. - **MERGE INTO** — upserts atômicos em tabelas UC existentes. A ferramenta certa para slowly changing dimensions, cargas incrementais e change data capture. #### Qualidade Bronze As tabelas Bronze de produção precisam de mais do que valores brutos. Ao longo do curso, você enriqueceu e protegeu seus dados ingeridos: - **Colunas `_metadata`** — capturam `file_name` e `file_modification_time` durante a ingestão para linhagem, auditoria e depuração - **Coluna `_rescued_data`** — preserva registros que não correspondem ao esquema de destino como strings formatadas em JSON, evitando a perda silenciosa de dados - **Tratamento de JSON** — achata dados semiestruturados em colunas consultáveis usando STRING, STRUCT (com `schema_of_json` + `from_json`) ou o novo tipo de dado VARIANT #### O Ciclo de Ingestão e Refinamento A barra coral representa o fluxo contínuo de dados pela Arquitetura Medallion. As tabelas Bronze produzidas pelo LakeFlow Connect alimentam tabelas Prata limpas, que por sua vez alimentam tabelas ouro curadas — com cada camada refinada de forma incremental e governada pelo Unity Catalog.

Apache Spark™ Declarative Pipelines



Leve Seus Pipelines de Ingestão Mais Longe
Agora que você compreende os fundamentos da ingestão de dados com LakeFlow Connect — — desde o armazenamento cloud e conectores gerenciados até metadados, dados resgatados, JSON e MERGE INTO — — o próximo passo é orquestrar pipelines de ponta a ponta com Spark Declarative Pipelines.
O Declarative Pipelines permite definir tabelas de transmissão e visões materializadas com SQL ou Python simples, enquanto o Databricks cuida da resolução de dependências, atualização incremental, qualidade de dados e orquestração. Combinado com o Auto Loader, é a abordagem recomendada para ingestão em produção em escala.
