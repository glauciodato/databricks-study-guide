Ingestão de Dados com LakeFlow Connect

Visão Geral

Este curso oferece uma introdução abrangente ao LakeFlow Connect, uma solução escalável e simplificada para ingestão de dados no Databricks a partir de uma ampla variedade de fontes. Você começará explorando os diferentes tipos de conectores do LakeFlow Connect (Standard e Managed) e aprenderá diversas técnicas de ingestão de dados, incluindo ingestão em lotes, em lotes incrementais e por transmissão. Você também revisará os principais benefícios do uso de tabelas UC e da Arquitetura Medallion.

Em seguida, você desenvolverá habilidades práticas para ingestão de dados a partir de armazenamento de objetos em cloud usando os Conectores Standard do LakeFlow Connect. Isso inclui trabalhar com métodos como CREATE TABLE AS SELECT (CTAS), COPY INTO e Auto Loader, com ênfase nos benefícios e considerações de cada abordagem. Você também aprenderá como adicionar colunas de metadados às suas tabelas de nível Bronze durante a ingestão na Databricks Data Intelligence Platform. O curso aborda ainda como tratar registros que não correspondem ao esquema da tabela usando a coluna de dados resgatados, além de estratégias para gerenciar e analisar esses dados. Você também explorará técnicas para ingestão e achatamento de dados JSON semiestruturados.

Na sequência, você explorará como realizar ingestão de dados em nível empresarial usando os Conectores Managed do LakeFlow Connect para trazer dados de bancos de dados e aplicações SaaS (Software como Serviço). O curso também apresenta o Partner Connect como uma opção para integrar ferramentas de parceiros às suas cargas de trabalho de ingestão.

Por fim, o curso encerra com estratégias alternativas de ingestão, incluindo operações MERGE INTO e o uso do Databricks Marketplace, equipando você com uma base sólida para apoiar casos de uso modernos de engenharia de dados.

Objetivos Finais

  • Descrever o LakeFlow Connect como uma solução escalável e simplificada para ingestão de dados no Databricks a partir de diversas fontes.
  • Revisar os benefícios das tabelas UC e da Arquitetura Medallion.
  • Demonstrar como ingerir dados de armazenamento de objetos em cloud em tabelas UC usando CREATE TABLE AS, COPY INTO e Auto Loader, incluindo a captura de metadados de arquivos de Entrada em tabelas da camada Bronze.
  • Explicar como as colunas resgatadas são utilizadas durante a ingestão para gerenciar registros malformados.
  • Ilustrar técnicas para ingestão e achatamento de dados JSON semiestruturados a partir de armazenamento em cloud.
  • Descrever as opções disponíveis para ingestão de dados de sistemas empresariais usando os Conectores Managed do LakeFlow Connect.
  • Discutir métodos alternativos de ingestão, como MERGE INTO e Databricks Marketplace.

A. Pré-requisitos

Antes de iniciar este curso, os alunos devem estar familiarizados com o seguinte:

  • Compreensão básica da Databricks Data Intelligence Platform, incluindo Databricks Workspaces, Apache Spark, Delta Lake, a Arquitetura Medallion e Unity Catalog.
  • Compreensão básica de fluxos de trabalho de ingestão de dados (lotes, transmissão, incremental) e princípios gerais de ETL
  • Experiência com diversos formatos de arquivo (por exemplo, Parquet, CSV, JSON, TXT).
  • Proficiência em SQL e Python.
  • Familiaridade com a execução de código em Databricks Notebooks.

B. Informações de Configuração do Workspace

B1. Workspace Vocareum Fornecido pela Databricks (Recomendado)
