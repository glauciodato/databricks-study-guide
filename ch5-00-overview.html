Técnicas Avançadas com Apache Spark™ Declarative Pipelines

Visão Geral

Este curso fornece uma exploração prática de Apache Spark™ Declarative Pipelines (SDP) — o framework moderno do Databricks para construir streaming pipelines de nível de produção. Você vai aprender padrões avançados de design de pipeline, práticas robustas de data quality e técnicas de integração que vão além do básico — preparando você para construir, manter e escalar sistemas de dados do mundo real.

Objetivos do Curso

Ao completar este curso, você será capaz de:

Módulo Foco O que Você Vai Aprender
Módulo 1 Multi-Flow + Liquid Clustering + Data Quality Escrever múltiplas fontes em uma única target table, aplicar liquid clustering e enforçar data quality com expectations
Módulo 2 Multiplex Streaming + Delta Sinks + Iceberg Implementar o padrão multiplex para ingestão multi-event, escrever em tabelas externas via sinks e habilitar leitura cross-platform via Delta UniForm
Módulo 3 CDC Avançado (AUTO CDC INTO) Automatizar SCD Type 2 com AUTO CDC INTO, rastrear histórico de mudanças e analisar objetos do pipeline
Módulo 4 Data Quality Avançada + Quarantine Projetar pipelines resilientes com ingestão STRING, schema evolution e o padrão quarantine para zero perda de dados

A. Pré-requisitos

Antes de iniciar este curso, os alunos devem estar confortáveis com:

  1. Spark Declarative Pipelines — Conclusão do curso "Build Data Pipelines with Apache Spark Declarative Pipelines" ou familiaridade com CREATE OR REFRESH STREAMING TABLE, CONSTRAINTS, AUTO CDC INTO e settings de pipeline
  2. SQL — Proficiência em SQL incluindo queries complexas, joins e funções de janela
  3. Databricks Workspace — Experiência navegando a UI do Databricks, incluindo notebooks, jobs e Unity Catalog
  4. Data Engineering Concepts — Entendimento da Medallion Architecture (Bronze/Silver/Gold), streaming vs batch processing e formatos de dados (JSON, CSV, Delta)
