Aula - Adicionando Colunas de Metadados na Ingestão

Visão Geral

Nesta aula, você aprenderá como colunas de metadados, como o nome do arquivo fonte e o horário de modificação, podem ser adicionadas durante a ingestão de dados do cloud storage usando a coluna _metadata, permitindo que contextos essenciais sejam capturados para cada linha durante a criação de tabelas no Lakehouse.

Objetivos de Aprendizado

Ao final desta aula, você será capaz de:

  1. Explicar o propósito das colunas de metadados e por que elas são valiosas durante a ingestão de dados
  2. Usar a coluna _metadata para adicionar metadados em nível de arquivo como nome do arquivo e horário de modificação durante a criação de tabelas
  3. Identificar os campos comuns de _metadata incluindo _metadata.file_name e _metadata.file_modification_time

B. Campos Comuns de Metadados de Arquivo

Para adicionar colunas de metadados durante a ingestão, você pode usar a coluna especial _metadata. Esta é uma coluna oculta disponível para todos os formatos de arquivo de Entrada.

Adicionar timestamp da última modificação do arquivo
_metadata
.file_modification_time
>
2024-10-07T18:04:42.885+00:00
Adicionar nome do arquivo de entrada
_metadata
.file_name
>
part-00002-7573-1-c000.file_name
Documentação
  • Coluna de Metadados de Arquivo
EXPANDIR PARA NOTAS ADICIONAIS
Para incluir a coluna _metadata no DataFrame retornado, você deve selecioná-la explicitamente na sua query de leitura ao especificar a fonte. A coluna _metadata contém diversos campos úteis. Dois campos comuns incluem:
  1. _metadata.file_modification_time – fornece o timestamp da última modificação do arquivo de Entrada
  2. _metadata.file_name – retorna o nome do arquivo fonte para cada linha

C. Conclusão

Nesta aula, você aprendeu como adicionar colunas de metadados de arquivos de fonte de entrada durante a ingestão de dados:

  • Colunas de metadados preservam o contexto sobre a origem dos dados, o que é valioso para auditoria, linhagem e depuração.
  • A coluna especial _metadata é uma coluna oculta disponível para todos os formatos de arquivo de entrada. Você deve selecioná-la explicitamente na sua query de leitura.
  • Dois campos comumente utilizados:
  • _metadata.file_modification_time: O timestamp da última modificação do arquivo de entrada
  • _metadata.file_name: O nome do arquivo fonte para cada linha
